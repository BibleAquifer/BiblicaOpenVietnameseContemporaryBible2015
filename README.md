# _Biblica® Open Vietnamese Contemporary Bible 2015_ Aquifer Resource

This repository (`BiblicaOpenVietnameseContemporaryBible2015`) contains an Aquifer Bible resource with resource-level metadata and content files in USFM and USX formats.
